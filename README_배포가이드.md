# 🚀 180일 전인적 성장 프로젝트 — 배포 가이드

## 📦 파일 구성 (총 6개)

```
📁 프로젝트 폴더/
├── index.html              ← 메인 화면 (대시보드)
├── app.js                  ← 앱 두뇌 (모든 기능)
├── data_vocabulary.json    ← 영어 단어 208개
├── data_hanja.json         ← 한자 123개
├── data_trivia.json        ← 상식 문제 118개
└── data_messages.json      ← 180일 동기부여 메시지
```

⚠️ **중요:** 6개 파일은 반드시 **같은 폴더**에 있어야 합니다.

## 1️⃣ 가장 쉬운 방법: 바로 실행 (테스트용)

1. 6개 파일을 모두 한 폴더에 다운로드
2. `index.html`을 더블클릭 → 브라우저에서 열림

> ⚠️ 단, 이 방법은 일부 브라우저에서 JSON 로딩이 막힐 수 있습니다.
> 그럴 땐 아래 **GitHub Pages** 방법을 쓰면 완벽하게 작동합니다.

---

## 2️⃣ 추천: GitHub Pages 무료 배포 (어디서나 접속)

### STEP 1. GitHub 가입 (이미 있으면 생략)
- https://github.com → Sign up → 이메일·비밀번호·사용자명 입력

### STEP 2. 저장소 만들기
1. 우측 상단 **+** → **New repository**
2. 이름: `growth180` (원하는 이름)
3. **Public** 선택 ✅
4. **Create repository**

### STEP 3. 파일 6개 업로드
1. **Add file** → **Upload files**
2. 6개 파일을 전부 드래그 앤 드롭
3. 아래 **Commit changes** 클릭

### STEP 4. Pages 켜기
1. 저장소 **Settings** → 좌측 **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / 폴더: **/ (root)** → **Save**
4. 1~2분 뒤 새로고침하면 주소가 나옵니다:
   ```
   https://[사용자명].github.io/growth180/
   ```

### STEP 5. 접속 & 공유
- 위 주소를 아드님·가족에게 공유
- **QR코드**로 만들면 더 편합니다 (qr-code-generator.com)

## ❓ 문제 해결

| 증상 | 해결 |
|------|------|
| "loading"에서 안 넘어감 | JSON 파일 6개가 같은 폴더에 있는지 확인 |
| 화면이 안 바뀜 | 새로고침 (Ctrl+F5 / 모바일은 캐시 삭제) |
| 접속이 안 됨 | 저장소가 Public인지, 1~2분 기다렸는지 확인 |
| 기록이 사라짐 | 같은 브라우저·기기에서 접속하세요 (기록은 기기에 저장됨) |
